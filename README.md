# keyroost-nix

> [!WARNING]

This repository provides Nix packaging for [keyroost](https://github.com/framefilter/keyroost), a Rust-based Management UI and CLI for U2F/FIDO2 and other hardware security keys.

## Usage

You can use this flake to build or run the application directly using Nix:

### Run
To execute the application without installing it:

```sh
nix run github:your-username/keyroost-nix

```

### Build

To build the package and output it to the result directory:

```sh
nix build

```

The resulting binaries will be available in `./result/bin/`.

### Development Shell

To enter a development environment with `nixfmt` and `nixd` pre-installed for working on this Nix configuration:

```sh
nix develop

```

## Features

* **Standard Builds**: Packages both `keyroost` (GUI) and `keyroostctl` (CLI).
* **Hardened**: Includes `patchelf` post-fixup to ensure the binary correctly locates its runtime dependencies (such as `libpcsclite` and X11/Wayland libraries) without requiring system-wide LD_LIBRARY_PATH modifications.
* **Flake-parts**: Modular architecture using `flake-parts`.

## Prerequisites

* **PC/SC Daemon**: `keyroost` requires a host PC/SC daemon to communicate with smart cards. Ensure `pcscd` is running on your system (e.g., `services.pcscd.enable = true;` on NixOS).
* **Graphics**: On Linux, the GUI component requires standard X11/Wayland and OpenGL libraries, which are handled by the package build inputs.
